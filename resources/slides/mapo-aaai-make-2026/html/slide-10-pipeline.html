Read The Flow In 3 Moves
Planner-specific input We begin with raw MAPF traces and optional planner arguments, not a custom explanation API.
Ontology mapping generate_kg.py binds those fields to ontology relations and asserts RDF triples automatically.
Planner-agnostic output The same knowledge graph then drives SPARQL queries, replay views, and operator-facing explanations.
python generate_kg.py --log_file <json> --ontology <ttl> --output <ttl>
SPARQL results are then populated into natural-language explanation templates, producing human-readable answers from the same graph.
