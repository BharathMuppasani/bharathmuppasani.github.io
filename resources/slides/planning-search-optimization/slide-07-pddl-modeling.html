How Do We Describe the Environment So a Planner Can Search It?

Once the navigation intuition is clear, we need a compact description of the world: what objects exist, which actions are allowed, and when goals are satisfied.

What the model must capture

The planner does not see pixels. It sees structure.

Locations, connectivity, package locations, carrying status, and goal destinations are the parts of the environment that change search decisions.
