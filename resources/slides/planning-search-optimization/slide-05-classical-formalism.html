Graph Search

BFS and DFS Explore the Same Grid Very Differently

We start with the navigation subproblem only: move the warehouse robot from mailroom to lab on the same grid world we will later model symbolically.

Breadth-First Search

Wave expansion

BFS explores all nodes at depth d before touching depth d + 1. It guarantees shortest paths in unweighted graphs, but the frontier grows rapidly.

Depth-First Search

Commit early

DFS follows one branch deeply before backtracking. Memory stays small, but the first solution can be badly misguided.

Search strategy changes the computation, not the problem. The start, goal, and grid are identical in both panels.
