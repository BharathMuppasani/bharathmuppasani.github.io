Planning Formalism

Predicates, Actions, Preconditions, Effects, Initial State, Goal State

In planning, a state is a set of facts. An action is usable only when its preconditions hold, and its effects define the next symbolic state.

Predicates

(at-robot hallway), (at-pkg A mailroom), (handempty).

Actions

Move, Pick, and Drop specify preconditions and effects over those predicates.

Initial State

Robot in hallway, A in mailroom, B in storage, hand empty, all corridors available.

Goal State

(at-pkg A lab) and (at-pkg B office).

Action schema example: Pick(packageA, mailroom)
Action schema
Preconditions

What must already be true?

(at-robot mailroom), (at-pkg A mailroom), and (handempty) must all hold before Pick is applicable.

Effects

What changes in the next state?

Add (carrying A). Delete (handempty) and (at-pkg A mailroom). The world graph stays the same; only the facts change.

Preconditions decide applicability; effects define the successor state.
Even one changed predicate creates a different node in planning-state search.
