Learning Routes

Two Ways to Learn Missing Decision Knowledge

Label-Based Learning
supervised / imitation setting

Learn from labeled good behavior.

If an expert, a planner, or solved traces tell us which action should be taken in each state, we can train a predictor for actions, heuristic values, or missing costs.

Training Signal

Action labels, solved plans, or expert choices.

Strength

Sample-efficient when high-quality labels exist.

Typical Use

Imitation policies or learned heuristics.

Reward-Based Learning
reinforcement learning

Learn from consequences instead of labels.

If no expert action is provided, the agent can still learn from delayed reward: successful deliveries, shorter travel, lower energy, and fewer failures.

Training Signal

Scalar reward, not action labels.

Strength

Useful when good labels are unavailable.

Typical Use

Reactive policies under repeated interaction.
