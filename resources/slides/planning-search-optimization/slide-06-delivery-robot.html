Heuristic Search

A* Uses Cost-So-Far Plus an Estimate of What Remains

A* searches on the same grid, but it ranks nodes using both cost accumulated so far and a heuristic estimate of the remaining cost.

A* Priority
f(n) = g(n) + h(n)
g(n)distance already traveled from the start
h(n)Manhattan distance from the cell to the goal
Heuristic Intuition

Prefer nodes that look closer to the goal.

On this grid, Manhattan distance is a useful estimate because each move changes the row or column by one unit.

A* is not magic. It still searches. It simply spends far less effort on branches that look geometrically unpromising.
