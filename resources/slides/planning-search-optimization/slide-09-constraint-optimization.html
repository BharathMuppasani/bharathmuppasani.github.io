Planning State Space

Search Grows by Testing Every Candidate Action in the Current State

The planner starts from one symbolic state and asks: which actions are applicable here, and what successor state would each valid action produce?

Current state s0
Robot at hallway, hand empty
(at-robot hallway) (at-pkg A mailroom) (at-pkg B storage) (handempty)

Goal facts remain unmet: (at-pkg A lab) and (at-pkg B office).

Move(hallway, mailroom)

Valid. The hallway is connected to the mailroom, so a new reachable state is created.

Move(hallway, storage)

Valid. This branch may help later because package B is waiting in storage.

Pick(packageA, mailroom)

Invalid now. The robot is not in the mailroom yet, so the precondition fails.

Drop(packageA, lab)

Invalid now. The robot is not carrying package A, so dropping is impossible.

Invalid actions are pruned, but every valid action still adds a new frontier state for the planner to evaluate next.
